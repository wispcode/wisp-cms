Overview
===========================================================

Wisp is a client-side CMS. There's no backend, database, or admin screen, only static files and a web server with URL rewriting.

**How it works**

- Pages are HTML or Markdown files in the `pages` folder.
- Layouts wrap pages with shared structure.
- Directives at the top of a page set its title, layout, and scripts.
- Editing access is controlled by folder permissions.
