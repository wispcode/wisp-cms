# Wisp CMS

A client-side flat-file CMS that conjures Markdown and HTML pages into templates. No build step, no database, no ghosts in the machine.

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![License](https://img.shields.io/badge/license-MIT-blue)
![Size](https://img.shields.io/github/size/wispcode/wisp-cms/dist/wisp.min.css)

------

## Features

- Markdown or HTML pages.
- Page settings via comment directives.
- Templates
- Per-page scripts and modules.
- Markdown containers.
- No build tools required.
